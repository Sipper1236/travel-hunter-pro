# Security policy

Travel Hunter Pro is a local-development prototype and is not approved for public deployment. Do not put credentials, traveler data, session captures, or exploitable details in public issues or pull requests.

For a suspected vulnerability, use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, contact the repository owner privately through GitHub. Include affected commit/file and reproducible steps, but omit real credentials and personal data.

Report exposed provider credentials to the relevant provider and rotate them. Removing a credential from the current files does not invalidate it or erase copies already fetched by Git clients.
